## Dantotsu — referenced for design, not copied

- Project: <https://github.com/rebelonion/Dantotsu>
- Licence: **GPL-3.0-or-later** (re-check the repository's current licence
  before redistributing if you ever vendor anything from it)

**What was taken:** the architectural idea that an AniList/MAL client should
synchronise a library through a **native API client** rather than by driving a
WebView, so tracking behaves identically on every platform and does not depend
on a site's markup.

**What was not taken:** no source code, assets, query strings, or translation
files. `src-tauri/src/anilist.rs` was written from scratch against AniList's
public documentation:

- OAuth 2.0 authorization-code grant — <https://docs.anilist.co/guide/auth/authorization-code>
- GraphQL v2 — <https://anilist.gitbook.io/anilist-apiv2-docs/>

**Licence consequence:** because no GPL-covered work is copied, linked, or
derived, AnimeHub is **not** subject to the GPL and remains MIT/Apache-2.0.
If you later copy Dantotsu code into this repository, the combined work
becomes GPL-3.0-or-later, and this file plus the `license` fields in
`src-tauri/Cargo.toml` and `package.json` must be updated to match.

## Rust crates

Runtime dependencies and what each is for:

| Crate | Purpose |
|---|---|
| `tauri`, `tauri-plugin-opener`, `tauri-plugin-deep-link` | App shell, system browser, OAuth deep link |
| `wry` / `tao` (transitive) | WebView and windowing |
| `aes-gcm`, `rand`, `sha2`, `subtle`, `zeroize`, `base64`, `hex` | Encryption, subkey derivation, constant-time compare, wiping |
| `keyring` (Linux) | XDG Secret Service |
| `windows-sys` (Windows) | DPAPI (`CryptProtectData`) |
| `reqwest` (rustls), `tokio`, `futures-util` | AniList HTTP/GraphQL client |
| `serde`, `serde_json`, `url`, `cookie`, `time`, `uuid`, `thiserror`, `log` | Serialisation, URL policy, cookie swapping |

All are permissively licensed (MIT and/or Apache-2.0) per their own metadata.
`reqwest` is built with `rustls-tls` rather than `native-tls`, so no OpenSSL
is linked into the Android binary. For the exact resolved set run:

```bash
cargo tree -e no-dev --prefix none | sort -u
cargo license          # with cargo-license installed
```

## Node packages

`@tauri-apps/api`, `@tauri-apps/plugin-opener`, `@tauri-apps/plugin-deep-link`
(MIT or Apache-2.0), with `vite` and `@tauri-apps/cli` as dev dependencies.
No runtime JavaScript framework is used and no CDN resources are loaded: the
CSP in `src-tauri/tauri.conf.json` restricts the app to `'self'`.
